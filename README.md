# Plataforma 3 Anos

Este projeto é um site de comemoração de aniversário de namoro com timeline e galeria de fotos.

## Como publicar no GitHub Pages

1. Crie um repositório no GitHub.
2. Copie todos os arquivos deste diretório para o repositório.
   - `amor.html`
   - `nosso-amor.html`
   - `index.html`
   - pasta `fotos/`
   - pasta `fotos_cards/`
3. Faça commit e push para o GitHub.
4. No GitHub, abra as configurações do repositório (`Settings`).
5. Vá em **Pages**.
6. Em **Source**, selecione o branch `main` ou `master` e a pasta `/ (root)`.
7. Clique em **Save**.
8. Aguarde alguns minutos e abra a URL fornecida pelo GitHub Pages.

## Como o site funciona

- `index.html` redireciona automaticamente para `amor.html`.
- O conteúdo principal está em `amor.html`.
- A galeria usa a pasta `fotos/`.
- A timeline usa a pasta `fotos_cards/`.

## URL final

A URL será algo como:

```
https://SEU_USUARIO.github.io/NOME_DO_REPOSITORIO/
```

Se quiser usar `nosso-amor.html` como página principal, basta renomear ou ajustar o redirecionamento em `index.html`.
